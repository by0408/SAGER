# Attribution and release status

This project reorganizes the author's existing SAGER main-experiment code and
layerwise-probe training pipeline. The author's source-code license has
not been chosen by this packaging task; no third-party license is implied.

The language-model and Detoxify weights are external dependencies and are not
redistributed here. The bundled dataset texts retain their original provenance
and applicable source terms; see `docs/DATASETS.md`. Publishing this folder should
preserve attribution and the author's decisions about code, probe and dataset
redistribution. No GitHub publication is performed by the package builder.
